# 点滴选择栏动效 Demo

当前界面只有两个Tab，顺序为：Tab1「展开键盘」（默认展示）、Tab2「相机场景」。旧独立“添加图片”Tab已移除，下文旧编号仅用于说明设计来源。相机场景选图后进入Tab1并增加一张图片。

Tab1在键盘收起和展开时都支持图片横向拖动、删除及点击“+”。键盘态点击“+”会按相同333ms联动收起键盘、进入单层选择栏状态；相机/相册自动添加图片，取消或添加后恢复默认双层面板。选择栏显示期间图片拖动被禁用。

直接打开 index.html，或在此目录运行 `python3 -m http.server 4174` 后访问 http://127.0.0.1:4174/ 。部署时上传此目录全部文件，不需要构建或安装依赖。

顶部 Tab 切换：图1点击相机；图2点击“+”。点击空白或按 Escape 关闭；点击“拍照/相机”或“从相册选择”都会立即自动添加一张设计稿中的照片，便于连续演示，无需系统相册或相机权限。图2默认一张 Figma 照片，可继续添加、横向滑动和删除；“+”位于最后一张后面。图1添加照片后进入图2。图2输入栏采用更新稿“点击输入或按住语音记录”，无光标。

## 视频动效分析与本 Demo 参数

参考 normal_video.mp4，时长3.533秒，30fps。对首次展开0.40–0.65秒附近逐帧取样，菜单从小尺寸迅速放大，后段逐渐稳定，无明显弹性回摆。首次可见到稳定约0.20秒（30fps时间精度约33ms）。关闭约0.17–0.20秒，为近似观察值。

视频只能测量画面，无法恢复原始工程的精确曲线、透明度轨迹和缩放起点。以下为参考视频拟合并应用于本Demo的参数，不声称是原视频作者的原始参数：

| 参数 | 本 Demo |
| --- | --- |
| 展开时长 | 200ms |
| 收起时长 | 167ms |
| 缓动 | cubic-bezier(0.2, 0.8, 0.2, 1) |
| 缩放 | 0.12 → 1，X/Y等比 |
| 透明度 | 0 → 1，同步渐入 |
| 缩放原点 | 50% 50%，菜单正中心 |
| 位移 | 菜单中心从当前触发按钮中心移至最终中心，动态计算 |
| 弹跳/旋转 | 无 |

两种场景共用同一个菜单和同一组参数。居中缩放是本次要求对参考动效方向的调整。闭合反向缩回当前按钮中心。最终展开态的8px基于卡片和菜单真实边界计算；中间状态菜单向按钮靠拢，因此不以8px作为每个中间帧的固定间距。快速切换从当前变换继续，避免跳帧。减少动态效果的系统偏好下时长缩短为1ms。

文件：index.html页面；styles.css布局；app.js交互与动效；assets本地素材；README参数说明。

## 场景2：图片栏横向拖动

图片外观沿用当前设计稿（76×76、圆角8、相邻间隔8）。支持鼠标按住或手机手指持续横向拖动，不需要进入排序模式。列表正常滚动，不进行逐张吸附；到达左右边缘后，继续拖动会出现逐渐增加的阻力，松手后整条列表自然回弹。右侧到达列表末尾时，“+”或最后一张图片与输入卡片右边缘保持12px间距；中间浏览位置不强制吸附。删除按钮和加号正常点击，拖动结束的点击被拦截以防误触。

最多9张；达到9张隐藏加号，删除后恢复。外观与输入卡片维持当前图2，不使用交互标注图中的键盘或卡片样式。photo-drag.js与photo-drag.css实现横向手势、边缘阻尼、回弹及12px边距。

## 第三个 Tab：展开键盘

点击「展开键盘」Tab进入双层面板初始状态。图片区是独立交互区域，点击图片不会弹键盘，仅底部文字/语音输入区域触发键盘。图片可添加、删除，最多9张。图片栏只有默认双层状态下可连续横向拖动，裁切范围限定在白卡内部；列表两端静止时距白卡边缘12px，越界有阻尼与整体回弹。

Figma默认态258:9995、选择栏态249:3360、键盘态258:11120，402×874。图标区和把手、灰底面板使用“整个面板（不包含输入框）.png”，包含20px逻辑阴影留边；原图836×634按418×317显示，可见面板为(12,506)、378×277。白卡改为真实DOM，照片、删除、语音、发送和加号均使用原始素材，从而支持真实交互。默认白卡(24,627)、354×144；选择栏态白卡(12,639)、378×144；键盘态白卡(12,397)、378×144。

点击默认态“+”，图标、把手及灰底下收淡出，白卡左右扩宽至12px边距，选择栏从当前加号居中缩放展开，不弹键盘。选择栏外任意区域的按下操作仅取消选择栏并恢复双层，不继续触发底层输入、图片、删除、导航或Tab。点击相机/相册自动加一张照片，然后恢复双层。选择栏距白卡8px。记录内容按参考图保留，并随层级变化联动；注释中“记录卡片距当前面板20px”优先于原稿默认8px/键盘24px等旧间距，三种端点均为20px；时间轴使用连续线层连接现有节点。

Tab2和Tab3统一使用TabBar.png二倍切图（804×166，显示402×83）。所有真实加号控件统一使用Frame 627.png（152×152，显示76×76）；不再有描边方框。原始两张输入卡切图仍保留在assets中供对照，场景3交互版本不将其整体当按钮。

点击底部文字区弹出切图键盘；点击上方内容、键盘右上方收起箭头或Escape返回。键盘是“输入法.png”（804×650），显示402×325，最终顶部549，不调用手机系统键盘。

参考此次更新的normal_video.mp4（5.2秒，约29.61fps），0.55–0.9秒附近可见工具层收起与键盘上升，过程约300–350ms；键盘和第三场景选择栏层级切换统一采用333ms及cubic-bezier(0.2,0.8,0.2,1)，为画面拟合值。统一进度驱动各层；前段图标、把手与灰底下移淡出，随后白卡向左右各扩12px。关闭过程中沿当前状态连续返回，Tab切换复位。系统减少动态效果开启时近乎立即切换。

keyboard-scene.js与keyboard-scene.css仅承载第三场景。已在浏览器核对两个端点坐标、原始切图加载、展开和返回、顶部导航固定及原场景选择栏。
